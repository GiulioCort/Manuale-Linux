Comando rm

Il comando rm (remove) permette di eliminare file e cartelle, quest'ultime solo non sono vuote, altrimenti si usa rmdir.

Sintassi

rm [opzioni] [file|directory]

Opzioni

-r o -R rimuove in modo ricorsivo tutto il contenuto della directory specificata.

Utilizzi

rm file rimuove file.

rm -r cartellaProva rimuove cartellaProva e tutto il suo contenuto.
