Comando mv

Il comando mv (move) permette di spostare file e directory e di cambiare il loro nome.

Sintassi

mv [sorgente] [destinazione]

Utilizzi

mv fileEsempio.txt file.txt rinomina fileEsempio.txt in file.txt.

mv fileEsempio.txt cartellaProva/ sposta fileEsempio.txt nella directory cartellaProva (funziona anche con i percorsi assoluti).

mv cartellaProva cartella2/ sposta cartellaProva dentro cartella2.
