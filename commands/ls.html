Comando ls

Il comando ls (list directory) permette di elencare i file e le cartelle.

Sintassi

ls [opzioni] [percorso] dove [opzioni] è opzionale.

Opzioni

-a (all) visualizza tutti i file, compresi quelli nascosti (il cui nome inizia per .).

-l produce un elenco esteso e dettagliato di tutti i file e directory.

Utilizzi

ls visualizza il contenuto della directory corrente.

ls cartellaProva visualizza il contenuto di cartellaProva, che si trova all'interno della cartella corrente.

ls -la visualizza il contenuto della cartella corrente, in un elenco dettagliato, completo anche di file nascosti.
