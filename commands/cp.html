Comando cp

Il comando cp (copy) permette di copiare file e directory.

Sintassi

cp [sorgente] [destinazione]

Utilizzi

cp fileEsempio.txt file.txt crea una copia di fileEsempio.txt chiamata file.txt (nella stessa directory).

cp fileEsempio.txt cartellaProva/file.txt crea una copia di fileEsempio.txt chiamata file.txt nella directory cartellaProva.

cp cartellaProva cartella2/ crea una copia della directory cartellaProva chiamata cartella2.
