Comando cd

Il comando cd (change directory) permette di spostarsi tra le cartelle del filesystem.

Utilizzi

cd cartellaProva si sposta in cartellaProva, che è all'interno della cartella corrente.

cd /root si sposta nella cartella root, passata come indirizzo assoluto tramite la / iniziale.

cd .. si sposta nella cartella superiore a quella corrente. Per tornare alla cartella ancora prima è possibile scrivere ../.. e così via quante volte si vuole.
